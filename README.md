# Compiler Design Lab Using LEX and YACC

## Overview

This project implements a simple compiler front end and back end
using LEX, YACC, and C.

It demonstrates lexical analysis, syntax analysis,
syntax-directed translation, three-address code generation,
code optimization, and target-code generation.

## Features

- Lexical analysis using LEX/Flex
- Syntax analysis using YACC/Bison
- Assignment statements
- Arithmetic expressions
- While loops
- If statements
- If-else statements
- Nested control statements
- Three-address code generation
- Constant folding
- Basic loop-invariant code motion
- Assembly-like target-code generation
- Syntax-error detection

## Requirements

- GCC
- Flex
- Bison
- Linux or another compatible Unix-like environment
